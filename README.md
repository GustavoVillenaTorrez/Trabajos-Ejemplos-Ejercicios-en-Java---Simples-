# ☕ Ejercicios Prácticos de Programación en Java

## 📝 Descripción General
Este repositorio contiene una colección de proyectos y ejercicios desarrollados en Java. El objetivo de este repositorio es demostrar el dominio progresivo del lenguaje, comenzando con los fundamentos de la Programación Orientada a Objetos (POO) hasta llegar a conceptos avanzados como el manejo de colecciones, inmutabilidad, resolución de problemas arquitectónicos y persistencia en bases de datos.

## 📂 Estructura de los Ejercicios

A continuación, se detalla el propósito de cada módulo/carpeta del repositorio:

* **Cuenta / Numeros / PerroProgramador:** Ejercicios introductorios sobre el modelado de clases, instanciación de objetos, encapsulamiento y el uso básico de atributos y métodos.
* **ConstructorMetodoEstatico / MetodoEstaticoInterfaz:** Prácticas enfocadas en el uso del modificador `static`, comprender el alcance de los métodos de clase vs. métodos de instancia, y la implementación de métodos estáticos dentro de interfaces (característica de Java 8+).
* **Herencia / ClasesAbstractas:** Ejercicios que aplican los pilares de la POO. Creación de jerarquías de clases, reutilización de código y definición de plantillas base a través de clases abstractas.
* **Diamante:** Resolución del clásico "Problema del Diamante" (herencia múltiple) utilizando el sistema de interfaces de Java.
* **Inmutable:** Diseño y creación de clases inmutables (ej. uso de `final`, sin métodos *setters*), garantizando la seguridad e integridad de los datos en entornos concurrentes.
* **Colecciones / ListaPerroProgramador:** Uso intensivo del *Collections Framework* de Java (List, Set, Map) para el almacenamiento dinámico, manipulación y recorrido de conjuntos de objetos.
* **Persistencia y Base de Datos:** . Ejercicios orientados a la conexión con bases de datos, operaciones CRUD y el guardado persistente de la información generada por las clases.

## 🛠️ Tecnologías y Conceptos Aplicados
- Lenguaje: **Java**
- Paradigma: **Programación Orientada a Objetos (POO)**
- Colecciones y Estructuras de Datos.
- Conexión a Bases de Datos (JDBC / ORM).
